# DesignStash

DesignStash is a modern desktop application built for performance and reliability.

## Tech Stack
- **Framework**: [Electron](https://www.electronjs.org/)
- **Frontend**: [React](https://reactjs.org/) with [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/) (via `electron-vite`)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Database**: [SQLite](https://www.sqlite.org/)
- **Package Manager**: [pnpm](https://pnpm.io/)
- **Primary Platform**: optimized for Apple Silicon (macOS arm64)

## Development

### Prerequisites
- Node.js (Latest LTS recommended)
- pnpm

### Commands
- **Start Development Server**: `pnpm dev`
- **Build Application**: `pnpm build`
- **Run Type Checks**: `pnpm typecheck`
- **Run Linter**: `pnpm lint`
- **Run Unit Tests**: `pnpm test:unit`
